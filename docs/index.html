v3 · prompt para Fable 5.1

Tarea: construye Brainstorm, una app web para que una persona y
Claude lleguen entre los dos a la idea de una app y la entreguen como
prompt de tres partes para Fable 5.1, con sesiones que se retoman días
después, roles por prefijo con un bloque por rol y versiones del prompt
con motivo de descarte.

Límites: la app produce prompts, nunca apps; Claude no escribe en la
mesa sin confirmación; ninguna clave en docs/; no decidir el formato del
paquete para Navaja ni el criterio de salida de apps nuevas.

Terminado cuando: `cargo test` en verde con tests de sesiones, fichas,
mensajes con dos roles y versiones con descarte; `tests/e2e/usuario.spec.ts`
pasa: crea sesión, envía "crítico, auditor: …", acepta una propuesta,
genera v1, la descarta con motivo y comprueba la ficha de criterio; guion
de 5 pasos en móvil desde Pages, cada paso con resultado observable.

--- Anexos (recortables) ---
Contexto: backend axum + tokio en app/, SQLite en /data, frontend sin
build en docs/ llamando a Fly con CORS, modelo claude-fable-5-1.
Pantallas: Sesiones; Sesión con Mesa, Conversación y Prompts.
Fuera de alcance: multiusuario real, importar fichas entre sesiones,
cualquier cambio en Navaja.
Prefijo rol: para una lente; crítico, auditor: para varias, un bloque por rol. Sin prefijo, respuesta normal.
